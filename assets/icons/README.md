# Profile icons

Font Awesome Free 6.7.2 brand icons by Fonticons, Inc., licensed under CC BY 4.0.
Source: <https://github.com/FortAwesome/Font-Awesome/tree/6.7.2/svgs/brands>.
See [LICENSE.txt](LICENSE.txt) and the repository [LICENSE.CC-BY-4.0](../../LICENSE.CC-BY-4.0).

The SVGs have explicit black fill. PNG equivalents are rendered at 96 pixels high
with rsvg-convert for embedding in Word. SVGs are embedded in HTML and PDF.
Icons are decorative and accompanied by readable labels or URLs.

The upstream license text has two em dashes normalized to ASCII double hyphens.
